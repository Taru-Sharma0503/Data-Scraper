# Books Web Scraper 📚🕸️

## Introduction

This Python project scrapes book data from Books to Scrape
 using Requests and BeautifulSoup. It collects details for each book on a page, including the title, price, availability, product description, and rating, and saves them to a CSV file (webScraper.csv). The script also prints each book’s information to the console in a readable format. This project demonstrates web scraping techniques, working with HTML structures, navigating multiple pages, and storing structured data using CSV in Python.

## How to Run ▶️

1.Make sure Python is installed on your system.

2.Install the required libraries if not already installed:

pip install requests beautifulsoup4


3.Save the script as books_scraper.py.

Run the script using:

python books_scraper.py


Check the generated webScraper.csv file for the scraped book data.

## Features ✨

Scrapes book title, price, availability, description, and rating

Saves scraped data into a CSV file

Handles books without a description gracefully

Prints each book’s details to the console

Uses BeautifulSoup for HTML parsing and navigation
